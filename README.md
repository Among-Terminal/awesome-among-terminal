## Before you install

Community plugins listed here are not reviewed or endorsed by the Among Terminal project. Among shows requested access before a plugin runs. Read it and check the protection level; access review is not a code audit. See the [plugin user guide](https://among-terminal.github.io/plugins/) for access review and confinement details.

To install from a community repository, open Settings (`Ctrl+,`) > Plugins. Use Add source with its public GitHub `owner/repository` or URL. Previewing is read-only; choose Add source to save the source and catalogue. Under Available, choose Install and check the version, package and requested access. Installation leaves the plugin disabled. Turn it on under Installed, review required and optional access, then choose Accept and enable. See [plugin sources](https://among-terminal.github.io/plugins/#plugin-sources) and [installation](https://among-terminal.github.io/plugins/#installing).
